BitByteLab is an offensive security lab in Vietnam. We do vulnerability research, reverse engineering and web application testing, and we build the tools we use for that work. Most of them are MCP servers, so AI agents can run them too.

| Tool | What it does |
|---|---|
| [raijin](https://github.com/bitbytelabio/raijin) | Burp Suite extension that gives AI agents an MCP server with 160+ Burp operations, plus the Turbo engine for single-packet races, HTTP/2 and HTTP/3. |
| [microsoft-defender-mcp](https://github.com/bitbytelabio/microsoft-defender-mcp) | MCP server for Microsoft Defender XDR and Defender for Endpoint: hunting, threat intelligence, vulnerability management and gated response. |
| [filescan-mcp](https://github.com/bitbytelabio/filescan-mcp) | MCP server for Filescan.io: file and URL scanning, report search, reputation checks and threat intelligence. |
